# R1.2 Signal Model

LONG READY pipeline:

1. VKCO 10m candles from MOEX ISS.
2. Adaptive support/resistance = low/high of previous 20 completed candles, excluding the last 3 trigger candles.
3. Candidate trigger:
   - Adaptive Breakout + Hold, or
   - Adaptive Spring.
4. Volume gate:
   - breakout RVOL >= 1.20 on breakout candle;
   - spring RVOL >= 1.30 on spring candle.
5. IMOEX market gate:
   - latest IMOEX >= SMA20 × 0.995;
   - 1h IMOEX return >= -0.70%.
6. If all gates pass → READY and Telegram.
7. Otherwise → WAIT with explicit reason.

This replaces fixed historical price levels and keeps the monitor self-adjusting as VKCO price regime changes.
