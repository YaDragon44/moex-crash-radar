## Interpretation
- MILD EXIT preserves the most terminal value and has the lowest average turnover, but offers the smallest drawdown improvement.
- EARLY CUT offers the strongest drawdown reduction in reversal scenarios, but pays the highest return penalty.
- BASELINE remains a middle risk-control choice but is expensive in persistent falling-yield scenarios.
- None of the level-only policies protect against an initial rise in yields while regime remains A/B/C.

## Decision
NO PRODUCTION CHANGE.
All four candidates are Pareto non-dominated on the current four-scenario matrix, so this dataset is insufficient to justify changing production thresholds.
