# R1.3.2 — Official MOEX source notes

Primary research sources:

1. MOEX analytical product `Futures. Open interest intraday`.
   - statistics split by individuals and legal entities;
   - five-minute intervals;
   - ISS/API access;
   - subscription required for full product access.

2. MOEX FUTOI data guide.
   - single-instrument historical requests use a two-character underlying code;
   - historical period request supports `from` / `till`;
   - maximum 1000 rows per API response, therefore pagination is mandatory.

3. MOEX derivatives code specification.
   Candidate research mappings:
   - MX -> MIX -> MOEX Russia Index
   - Si -> Si -> USD/RUB
   - SR -> SBRF -> Sberbank ordinary shares
   - GZ -> GAZR -> Gazprom ordinary shares
   - LK -> LKOH -> LUKOIL ordinary shares

Important: an official derivatives code does not imply FUTOI coverage. The R1.3.2 live audit determines actual availability and marks unsupported/unauthorized sources N/A rather than synthesizing data.

Data licensing/access constraints are part of the Quality Gate. Internal research can only use data available under the applicable MOEX access/subscription terms; the repository must not redistribute raw licensed FUTOI history.
