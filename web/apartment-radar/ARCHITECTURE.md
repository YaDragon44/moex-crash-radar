# APARTMENT RADAR — ARCHITECTURE v1.0 BASELINE

## Runtime

Browser-only static application.

## Components

1. `index.html` — presentation and rendering logic.
2. `data/apartments.json` — supplied analytical dataset.
3. GitHub Pages — static hosting through the repository's existing publication mechanism.

## Explicit non-goals for R0.1

- No scraping.
- No market analysis.
- No backend.
- No database.
- No API integration.
- No generated listing URLs.

## Design principle

The first screen must make the current #1 apartment, rent, VALUE SCORE, Paveletskaya commute, mandatory-requirement status, main risk, and Diamond status visible immediately.
