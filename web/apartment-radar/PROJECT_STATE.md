# APARTMENT RADAR — PROJECT STATE

**Дата:** 14.09.2026

## Architecture

**v1.0 BASELINE**

- Static dashboard
- HTML/CSS/Vanilla JS
- Data source: `data/apartments.json`
- Hosting: existing GitHub Pages pipeline of `YaDragon44/moex-crash-radar`
- No backend
- No database
- No framework
- Dashboard does not search or analyze listings; it only renders supplied analytical data

## Current Release

**R0.1 — MVP UI**

## Scope

Implemented:
- Header and KPI strip
- Recommended cards with rank, rent, area, VALUE SCORE, status
- Four mandatory requirement indicators
- Transport block
- Rent / monthly total / move-in cost
- Main plus / main risk
- Direct-listing link guard (no generated URLs)
- Diamond Moscow block
- Changes block
- Watch List block
- My Choice Today block and call questions
- Unknown values rendered as `⚠️ требует подтверждения`
- Responsive fallback for smaller screens

## Data Rule

Only values present in `data/apartments.json` are rendered. Missing values remain unknown. No listing URL is generated by the UI.
