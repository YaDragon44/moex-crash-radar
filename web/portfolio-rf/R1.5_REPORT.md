# R1.5 Risk & Concentration

## Scope

Minimal risk/concentration layer over R1.4 Portfolio Health. No backend, no optimizer, no hidden score, no invented market/fundamental data.

## Implemented

- Portfolio concentration facts from the existing model weights.
- Largest position = SBERP 18%.
- Top-3 concentration = 48% (18% + 16% + 14%).
- Top-5/Core = 70%.
- Finance block = 30% (SBERP 18% + T 12%).
- Cash reserve = 10%.
- Transparent per-position concentration flag:
  - <=14%: normal
  - 15-20%: elevated
  - >20%: critical
- Thresholds are explicitly labeled as internal project policy assumptions, not MOEX/CBR regulation.
- Rule: do not add to an already elevated-concentration position while valuation is N/D.
- Rebalancing preference remains new cash flows before mechanical selling.

## Integrity constraints

- Model portfolio weights are not represented as live brokerage positions.
- Concentration is not treated as an automatic sell signal.
- Valuation remains N/D where inputs are insufficient.
- BUY/ADD remains blocked without validated valuation.
- Existing manual MOEX quote refresh architecture remains unchanged.

## Expected status

Portfolio health remains YELLOW: concentration is visible and controlled, but data-quality and valuation coverage are still incomplete.
