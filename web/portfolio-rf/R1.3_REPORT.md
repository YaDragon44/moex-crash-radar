## Data-quality semantics
- COMPLETE: primary source and critical fundamental inputs for the current layer are available.
- PARTIAL: primary source/report exists but critical valuation inputs are incomplete.
- MISSING: current primary-source review is not completed.
- FRESH: current H1/Q2 2026 primary source verified for this release.
- UNKNOWN: freshness was not re-verified in this release.
