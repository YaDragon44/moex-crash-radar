# R1.4 Portfolio Health

## Status
IMPLEMENTED / PRE-MERGE VALIDATION REQUIRED

## Scope
Adds a portfolio-level health layer on top of the existing R1.3 data-quality and valuation gates without adding backend services, polling, optimizers or pseudo-precision.

## Health logic
The overall status is intentionally transparent and non-numeric. It uses five visible dimensions:
- Data quality
- Valuation coverage
- Concentration
- Risk visibility
- Actionability

Current model-portfolio facts used by the UI:
- Core: 70%
- Growth: 20%
- Cash: 10%
- Financial sector concentration: SBERP 18% + T 12% = 30%
- Primary-source freshness: 3/10
- Valuation coverage: 0/10

These are model-policy facts from the project baseline, not verified live brokerage weights.

## Decision
Overall health remains YELLOW. New BUY/ADD actions remain blocked because valuation coverage is 0/10 and most positions still lack fully fresh/reverified fundamental inputs.

## Architecture
Static GitHub Pages only. Manual MOEX quote refresh retained. No backend, database, auto-refresh, portfolio optimizer, VaR, Monte Carlo, hidden 0-100 score or invented valuation.
