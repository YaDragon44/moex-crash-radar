# R1.6 — Decision Engine 2.0

## Scope
Minimal transparent decision layer over the existing R1.5 model portfolio. No backend, optimizer, hidden score or invented valuation.

## Decision gate
A new BUY/ADD action requires all of the following:
1. usable/fresh fundamental evidence;
2. confirmed attractive valuation;
3. acceptable risk;
4. concentration that permits increasing the position.

If valuation is N/D, BUY/ADD is blocked. Missing fundamentals prevent an evidence-based change. Elevated concentration blocks adding. SELL is not inferred from price loss or missing data; it requires a verified thesis break, unacceptable risk, or justified overvaluation.

The engine therefore returns HOLD / DO NOT ADD / WATCH states with explicit reasons and change triggers.
