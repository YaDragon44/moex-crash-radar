# Portfolio RF — R1.2 Price & Valuation Layer

Date: 2026-09-12

## Goal
Introduce an explicit, reproducible valuation gate between live market quote and investment action.

## What changed
- Release identity updated to R1.2.
- Market quote and fair-value assessment remain strictly separated.
- Candidate valuation methods are declared per business type.
- Missing valuation inputs resolve to `Н/Д`, not an invented fair value.
- BUY/ADD is blocked while valuation state is `Н/Д`.
- Valuation coverage is visible as 0/10 until a position has a complete verified calculation.
- MOEX loaded-count logic uses unique SECIDs via `Set`.

## Integrity rule
A `дёшево / справедливо / дорого` label is allowed only when current quote, dated financial inputs and a relevant reproducible valuation method are all available. Otherwise status is `Н/Д`.

## Non-goals
No backend, polling, target-price guessing, 0–100 score, optimizer, auto-trading or pseudo-precision was added.

## Acceptance
R1.2 is a framework release. It is technically complete when CI/Pages pass. Investment valuation coverage intentionally remains 0/10 until verified issuer-specific inputs are added in the next data-quality/valuation population step.
