# R1.2 Acceptance Criteria

1. Production UI identifies as R1.2.
2. Market quote and valuation are separate concepts in the UI.
3. `Н/Д` is the only valuation state while required inputs are incomplete.
4. No BUY/ADD action is presented for positions with `Н/Д` valuation.
5. Candidate valuation method is disclosed per position.
6. MOEX fetch remains manual, fail-soft and timeout-protected.
7. Loaded-count uses unique SECIDs.
8. No backend, scheduler, local storage, service worker or auto-trading is introduced.
9. CI and GitHub Pages deployment must pass before release is marked green.
